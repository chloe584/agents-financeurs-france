# Valorisation par multiples (FR)

## Méthodes

### Comparables boursiers
- Univers : Euronext Paris (CAC 40, SBF 120, CAC Mid 60, CAC Small)
- Multiples : EV/EBITDA, EV/EBIT, EV/CA, P/E

### Transactions comparables
- Sources : Mergermarket, Capital Finance, Les Echos, Argos Mid-Market

### Argos Mid-Market Index
Multiples EV/EBITDA médian transactions LBO/strat mid-market européen. Hist 2015-2025 : ~9,0x à 10,5x.

## Multiples sectoriels typiques FR (2025)

| Secteur | EV/EBITDA | EV/CA |
| ------- | --------- | ----- |
| Industrie | 6-8x | 0,7-1,2x |
| Services B2B | 8-11x | 1,0-2,0x |
| Tech/SaaS | 12-25x | 4-10x |
| Luxe | 15-25x | 3-6x |
| Médias | 6-10x | 1,0-2,5x |
| Distribution | 5-8x | 0,3-0,8x |

## Ajustements

- Size discount (illiquid) : 20-30%
- Décote minoritaire : 15-25%
- Prime de contrôle : 20-30%
