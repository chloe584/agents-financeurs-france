# Comptes courants intragroupes (4511)

## Cadre légal

L.511-7 CMF autorise les opérations de trésorerie intragroupe (contrôle >= 50%). Convention obligatoire (art. L.227-10 C.com en SAS).

## Plan comptable

| Compte | Intitulé |
| ------ | -------- |
| 4511 | Compte courant intragroupe |
| 4512 | Intérêts courus 4511 |
| 4551 | C/C associé personne physique |
| 4558 | Intérêts courus 4551 |

## Règle du miroir

Solde 4511 (A) + Solde 4511 (B) = 0 €. Tolérance 0 exact au 31/12.

## Calcul des intérêts (art. 39-1-3° CGI)

Taux fiscal max = TMP des prêts à taux variable aux entreprises non financières > 2 ans (BdF, trimestriel).

Intérêts annuels = Solde moyen × Taux fiscal max × Nb jours / 365

## Écritures types

### Versement A vers B
A : Débit 4511.B / Crédit 5121
B : Débit 5121 / Crédit 4511.A

### Intérêts annuels au 31/12
A : Débit 4512.B / Crédit 762
B : Débit 661 / Crédit 4512.A

## Convention - clauses

1. Périmètre sociétés
2. Centralisateur
3. Plafond de découvert
4. Taux d'intérêt (taux fiscal max - 0,25 à 0,50%)
5. Modalités remboursement
6. Durée + dénonciation

## Obligation annuelle (SAS)

Convention réglementée (L.227-10 C.com) : rapport spécial du Président + approbation AGO.
