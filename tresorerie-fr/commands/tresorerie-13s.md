# /tresorerie-13s

## Étapes

1. Demande inputs (trésorerie départ, clients, fournisseurs, salaires, URSSAF, TVA, IS, loyers, emprunts)
2. Construit tableau S+0 à S+12
3. Calcule KPI : BFR, DSO, DPO, FCF, runway, burn rate
4. Modélise 3 scénarios (base / prudent / stress)
5. Génère xlsx avec graphique
6. Identifie semaines de tension + actions correctrices
