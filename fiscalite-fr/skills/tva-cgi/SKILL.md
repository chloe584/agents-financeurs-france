# TVA française (CGI)

## Taux 2026

| Taux | Application | Référence |
| ---- | ----------- | --------- |
| 20 % | Taux normal | CGI 278 |
| 10 % | Restauration, transports | CGI 279 |
| 5,5 % | Aliments, livres, spectacles | CGI 278-0 bis |
| 2,1 % | Médicaments, presse | CGI 281 quater |

## Régimes déclaratifs

| CA HT | Régime | Périodicité |
| ----- | ------ | ----------- |
| < 36,8 K€ (services) ou 91,9 K€ (vente) | Franchise | Aucune |
| 36,8 K€–254 K€ / 91,9 K€–840 K€ | Réel simplifié | Annuel CA12 |
| > 254 K€ / 840 K€ | Réel normal | Mensuel CA3 |

## Opérations intracommunautaires

- Livraison UE B2B : exonérée (art. 262 ter I CGI), vérifier num TVA via VIES
- Acquisition UE : autoliquidation (lignes 03 + 17/19 CA3)
- Vente B2C UE > 10 K€/an : guichet OSS-UE

## Autoliquidation BTP

Sous-traitance bâtiment : CGI 283-2 nonies. Mention facture : "Autoliquidation par le preneur".

## Déductibilité

Conditions cumulatives (CGI 271). Exclusions (ann II 206) : véhicules tourisme, cadeaux > 73 €, logements.
